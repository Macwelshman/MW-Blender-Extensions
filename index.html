MW Blender Extensions

Install MW add-ons and receive future updates through Blender.

Drag and drop installation

  1. Open Blender and leave this page visible beside it.
  2. Drag the orange area on an extension card below into the Blender window.
  3. Confirm Blender's installation prompt.

The link installs the extension and adds the MW repository for future updates.

If dragging is unavailable, manually add https://raw.githubusercontent.com/Macwelshman/MW-Blender-Extensions/main/index.json under Preferences → Get Extensions → Repositories.
